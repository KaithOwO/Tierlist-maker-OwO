# GIF Tier List

A tier list maker for GIFs, images and videos that runs entirely in the browser.

- Drag items into tiers. Hover an item to play it, click it to see it full size.
- Load a folder of GIFs, images and videos; videos are converted to GIFs automatically.
- Add a source link to each item (⚙ Settings → Source links). Linked items show a 🔗 badge.
- Export everything as a `pack.js` file to share, or import someone else's pack.

## Putting your own list on this site

1. Open the site, click **Load folder** and pick the folder with your media.
2. Rank things and add source links.
3. ⚙ Settings → **Export pack** (tick "Include my ranking" if you want to share your ranking).
4. Upload the downloaded `pack.js` to the root of this repository. The site loads it automatically.

Keep `pack.js` under 100 MB (GitHub's file size limit); use a smaller "Max size" when exporting if needed.
